# PROYECYO-HTML-CSS
Descripción del Proyecto

Vive Verde es una tienda virtual dedicada a la venta de productos ecológicos y sostenibles. Su objetivo es ofrecer a los usuarios una forma fácil y segura de encontrar productos amigables con el medio ambiente, promoviendo hábitos de consumo responsables. El sitio fue desarrollado con HTML5 y CSS3, utilizando un diseño moderno, atractivo y adaptable a diferentes dispositivos.


Instrucciones de visualización.
es una pagina web con facil manejo tiene un Inicio,Productos,Quienes somos y contacto esta diseñada facil e intituiba para que el usuario pueda usarla de manera facil.


Tecnologías Utilizadas
HTML5: Utilizado para la estructura y organización del contenido de la página web.
CSS3: Utilizado para el diseño, estilos, animaciones y responsividad del sitio.
Git: Herramienta de control de versiones para gestionar los cambios del proyecto.
GitHub: Plataforma utilizada para almacenar y compartir el repositorio del proyecto.
Visual Studio Code: Editor de código empleado para el desarrollo de la aplicación web.

## Ejecutar en local

El sitio no requiere instalación de dependencias ni un proceso de compilación.
Desde la raíz del repositorio:

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Abre `http://localhost:3000/proyecto/`. Para detener el servidor, usa `Ctrl+C`.

## Funcionalidades

- Diseño adaptable a móvil y escritorio, navegación con teclado y búsqueda de productos.
- Catálogo por categorías, orden por precio y favoritos guardados en el navegador.
- Calculadora orientativa de emisiones mensuales de electricidad y transporte. Los factores y el alcance se explican en los resultados.
- El formulario de contacto descarga una consulta como archivo de texto. No envía mensajes: el proyecto no tiene un servidor de correo ni un backend de compras.

Las imágenes optimizadas están en `proyecto/assets/`. Las imágenes originales se conservan en `proyecto/imagenas_para_el_proyecto/`. Los estilos activos están en `proyecto/css/main.css` y el comportamiento compartido en `proyecto/js/main.js`.
