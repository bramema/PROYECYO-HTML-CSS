# PROYECYO-HTML-CSS
Descripción del Proyecto

Vive Verde es una tienda virtual dedicada a la venta de productos ecológicos y sostenibles. Su objetivo es ofrecer a los usuarios una forma fácil y segura de encontrar productos amigables con el medio ambiente, promoviendo hábitos de consumo responsables. El sitio fue desarrollado con HTML5 y CSS3, utilizando un diseño moderno, atractivo y adaptable a diferentes dispositivos.


Instrucciones de visualización.
es una pagina web con facil manejo tiene un Inicio,Productos,Quienes somos y contacto esta diseñada facil e intituiba para que el usuario pueda usarla de manera facil.


Tecnologías Utilizadas
HTML5: Utilizado para la estructura y organización del contenido de la página web.
CSS3: Utilizado para el diseño, estilos, animaciones y responsividad del sitio.
Git: Herramienta de control de versiones para gestionar los cambios del proyecto.
GitHub: Plataforma utilizada para almacenar y compartir el repositorio del proyecto.
Visual Studio Code: Editor de código empleado para el desarrollo de la aplicación web.
